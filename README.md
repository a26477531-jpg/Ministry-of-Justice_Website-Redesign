# 展望與探索月刊｜電子書櫃前端 Demo

以法務部調查局「展望與探索月刊」電子書櫃為參考，重新設計期刊搜尋、篩選與瀏覽介面的純前端 Demo。本專案為非官方設計示範。

目前版本採深藍色系，已移除收藏功能。網站提供直接瀏覽與篩選，沒有會員、登入或帳號功能。

![深藍色書櫃介面，目前版本已移除收藏功能](preview.png?v=d270b0c)

## 目前設計

- **配色：**參照原調查局網站的深藍風格，主色為 `#06285F`，選取狀態使用 `#0B3774`，鍵盤焦點使用金色 `#CFA449`。這是 Demo 採用的配色，並非經官方認證的識別規範。
- **排列：**書櫃會依螢幕寬度自動換行，也可切換為清單檢視。
- **資訊層級：**以出版年月作為期刊主標，搭配卷期與西元年月。
- **操作順序：**篩選區 → 結果筆數與排序 → 期刊書櫃 → 分頁 → 可收合的投稿資訊。

## 使用方式

下載本儲存庫，直接使用瀏覽器開啟 `index.html`。無須安裝套件、建置工具、Python、Node.js、資料庫或後端服務。

1. 在 GitHub 點選 **Code → Download ZIP**，下載並解壓縮。
2. 用 Chrome、Edge 或其他現代瀏覽器開啟 `index.html`。
3. 輸入 `115年10月`、`2026/10` 或 `第24卷`，體驗期別搜尋。

GitHub 的檔案頁顯示的是原始碼；實際操作 Demo 請使用瀏覽器開啟下載後的 HTML。

## 功能

- 期別關鍵字搜尋，支援民國與西元日期的常見格式。
- 出版年份、月份與刊物類型篩選，以及可移除的條件標籤。
- 新舊排序、書櫃／清單切換、分頁與無結果提示。
- 期刊資訊視窗，可查看期別並前往官方書櫃。
- 響應式版面與可收合的投稿資訊。

每頁顯示 8 筆資料；更改篩選或排序時會回到第一頁。年份與刊物類型會連動調整可選月份。

## 技術與資料儲存

所有搜尋、篩選、排序和分頁均在瀏覽器內完成。只有書櫃／清單的檢視偏好會儲存在瀏覽器的 `localStorage`；不儲存收藏或會員資料。瀏覽器不允許本機儲存時，仍可使用主要瀏覽功能。

修改介面與樣式可直接編輯 `index.html` 的 HTML 與 `<style>`；展示資料位於 `<script>` 中的 `issues` 陣列。修改後重新整理頁面即可，無須建置。

## 資料與限制

35 筆期刊資料及封面均為展示用途，並非完整或經核實的官方館藏。詳情視窗尚未串接各期正式閱讀／下載連結，提供的外部連結通往官方書櫃。

篩選範圍限於 Demo 內建資料，不會搜尋官方網站或 PDF 全文。

參考來源：[法務部調查局電子書櫃](https://www.mjib.gov.tw/eBooks/eBooks_Detail?CID=4&page=1)。
